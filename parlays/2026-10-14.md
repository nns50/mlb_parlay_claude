## Why NO BUILD Today?

### Doctrine: The Min-Edge Gate is Non-Negotiable

Per CLAUDE.md § "Parlay construction":

> **Minimum-edge gate (a leg must clear the vig to qualify).** Using the NO-VIG implied prob, a leg
> qualifies only if devigged edge (TrueP − no-vig ImplP) is **≥ +2pp standalone / ≥ +3-4pp to anchor a
> parlay**. Below that it's action, not value. **A slate with nothing clearing the bar → "NO BET" is a
> valid, correct output** — still show the scan + the closest looks (flagged -EV), but don't manufacture a
> daily ticket.

**Three blocking conditions:**

1. **Zero pricing available.** Without real book prices, the no-vig implied probability cannot be computed, and therefore the edge (TrueP − no-vig ImplP) is undefined. The framework cannot operate.

2. **Only one game on slate.** A parlay, by definition, requires ≥2 legs from different games. A single leg on an available game is not a parlay; the user asked for "a high chance +200 parlay," not a standalone.

3. **Recommended action in progress.** The Odds API subscription was cancelled or payment failed. This is a user-actionable issue, not a data trap. Reactivation at https://the-odds-api.com will restore:
   - Live pricing from all US books
   - `tools/odds_api.sh best` line-shopping
   - K-prop pricing on the paid tier (~1 credit per market)
   - CLV capture automation
   - All edge computations
