### ⚠ TOOLING TRAP FOUND — `truep.py --adj` silently drops every tag but the last

Pricing the two-tag stacks, `--adj wind_out_over --adj hitter_park_over` returned **+1.5pp, not +3.5pp**.
Cause: `truep.py:137` reads `args.adj.split(",")` and `--adj` is **not** `action="append"`, so argparse
keeps only the **last** occurrence and the first tag vanishes **with no warning**. Correct syntax is
comma-separated: `--adj wind_out_over,hitter_park_over`.

- **Direction of the error is conservative** (it understates edge), so no leg was ever over-priced by it —
  but it silently converts a two-tag stack into a one-tag leg, which under GLOBAL SHRINK is the exact
  difference between **+3.5pp (bettable)** and **+1.5pp (under gate)**.
- ⚠ **It cannot have affected Build A**, whose one stacked leg was hand-shown as `+1.5 × +2.0 = +3.5` and
  was killed by E5/D5 regardless — but it is a live trap for any future build that reaches for a stack.
- **Logged as a proposed hardening, not patched mid-run** (same discipline as the E6 mechanisation):
  `--adj` should either be `action="append"` or error on repeat.
